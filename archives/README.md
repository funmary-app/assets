# archives

過去の版のロゴとアイコンを、`v<版>/` ごとに置きます。中の構成は、`current/` と同じです (`icon/svg/`、`icon/png/` など)。

| フォルダ | 版 | 内容 |
| --- | --- | --- |
| `v1/` | 原案 | 最初の案 (Mary lamb) |
| `v2/` | v2 | `icon-light` (白地) と `icon-dark` (赤地) |
| `v3/` | v3 | `icon-light` (白地) と `icon-dark` (赤地) |

ここの SVG は凍結しているので、変更しないでください。PNG は `npm run build` で `current/` と同じように作られますが、SVG が変わらなければ結果も変わりません。

版を改める手順は、リポジトリ直下の [README.md](../README.md) の「版を改める」を見てください。
